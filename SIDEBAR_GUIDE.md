# Sidebar Toggle Feature

## ✨ Sidebar Controls

Your InterviewAI app now has a **collapsible sidebar** with easy toggle functionality!

## 🎯 How to Use the Sidebar

### **Opening the Sidebar**
- **Default**: Sidebar is open when you start
- **If Collapsed**: Click the **[>]** arrow button on the left edge of the screen
- The sidebar will slide open from the left

### **Closing the Sidebar**
- Click the **[X]** button at the top-right of the sidebar
- Or click the **[<]** arrow button
- The sidebar will collapse to give you more screen space

## 📋 What's in the Sidebar?

### **User Info**
- ⚙️ Settings header
- 👤 Your username

### **Interview Controls**
1. **Interview Mode**
   - Text Interview
   - MCQ Test

2. **Interview Topic**
   - Dropdown with all available topics
   - Python, Java, JavaScript, etc.

3. **Difficulty Level**
   - Beginner
   - Intermediate
   - Advanced

4. **Mode Indicator** (Text mode only)
   - 📄 RAG Mode (for topics with documents)
   - 🧠 LLM Mode (for other topics)

### **Statistics** (MCQ mode)
- Questions answered
- Current score
- Progress bar
- Accuracy percentage

### **Action Buttons**
- 🔄 **New Interview** - Start fresh
- 🚪 **Sign Out** - Logout

## 💡 Tips

1. **Collapse for Focus**: Hide the sidebar when you want to focus on the conversation
2. **Quick Access**: Open sidebar anytime to change settings
3. **Mobile Friendly**: Sidebar automatically adapts to screen size
4. **Settings Visible**: Top bar shows current topic, difficulty, and mode

## 🎨 Visual Indicators

### **Top Bar Shows**:
- 💬 InterviewAI logo
- Current topic (e.g., "Python")
- Difficulty level (e.g., "Intermediate")
- Interview mode (e.g., "MCQ Test")
- Hint: "← Settings in sidebar"

### **Sidebar Toggle Button**:
- **[>]** - Opens sidebar (when collapsed)
- **[<]** or **[X]** - Closes sidebar (when open)
- Located at the left edge of the screen
- Visible at all times

## 📱 Responsive Design

- **Desktop**: Sidebar open by default, easy to toggle
- **Tablet**: Sidebar can be collapsed for more space
- **Mobile**: Sidebar starts collapsed, opens on demand

## 🔄 State Persistence

- Your sidebar preference is remembered during the session
- Settings remain visible in the top bar even when sidebar is collapsed
- No need to reopen sidebar to see current settings

## ✅ Benefits

1. **More Screen Space**: Collapse sidebar for larger chat area
2. **Quick Settings**: Open sidebar to change topic/difficulty
3. **Clean Interface**: Hide controls when not needed
4. **Easy Access**: Toggle button always visible
5. **Context Aware**: Top bar shows current settings

Enjoy your clean, collapsible sidebar! 🚀
