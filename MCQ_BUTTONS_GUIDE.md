# MCQ Test with Clickable Options - Guide

## What's New

### 1. Sidebar Toggle Button
- **Location**: Top-left corner (☰ icon)
- **Function**: Click to hide sidebar, click again to show it
- **Design**: Clean white button with hover effect

### 2. MCQ Clickable Options
- **Display**: Questions show with 4 clickable buttons (A, B, C, D)
- **Layout**: 2x2 grid (A & C on left, B & D on right)
- **Style**: Like global exam platforms (clean, professional)
- **Interaction**: Click any option to submit your answer

## How MCQ Test Works

1. **Start Test**:
   - Select "MCQ Test" mode in sidebar
   - Choose topic and difficulty
   - Test starts automatically

2. **Answer Questions**:
   - Read the question displayed in a clean box
   - Click one of the 4 option buttons (🅰️ A, 🅱️ B, 🅲 C, 🅳 D)
   - Get instant feedback (✅ Correct or ❌ Incorrect)
   - Next question appears automatically

3. **Track Progress**:
   - Sidebar shows: Score (e.g., 7/10)
   - Accuracy percentage with progress bar
   - Questions answered count

4. **Complete Test**:
   - After 10 questions, see final score
   - Click "New Interview" to start fresh

## Troubleshooting

**Buttons not appearing?**
- Refresh the page (F5)
- Make sure you're in "MCQ Test" mode
- Check that a question is displayed

**Sidebar toggle not working?**
- Look for ☰ button in top-left corner
- Try refreshing the page
- Check browser console for errors

**Score not updating?**
- Score updates after each answer
- Check sidebar for current score
- Progress bar shows accuracy percentage
